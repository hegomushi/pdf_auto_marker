PDF 自動マーキング (Windows 版)
==================================================

PDF 内の表を自動で検出し、指定した単語や行にマーキング(ハイライト)を付けるツールです。
処理はすべてこの PC 内で完結し、インターネットには接続しません。
Python などのインストールは不要です。


■ 起動方法
  PdfAutoMarker.exe をダブルクリックしてください。

  ※ 初回起動時に「Windows によって PC が保護されました」と表示された場合は、
     「詳細情報」→「実行」を押してください (署名のない exe のため表示されます)。
  ※ このフォルダ内のファイル (特に _internal フォルダ) は移動・削除しないでください。
     フォルダごとであれば、好きな場所へ移動できます。
     デスクトップから起動したい場合は、PdfAutoMarker.exe のショートカットを作成してください。


■ 使い方
  1. 「PDF を追加…」または「フォルダを追加…」でマーキングしたい PDF を選びます。
  2. 「単語マーキング」「行マーキング」タブでルールを追加・編集します。
       - 単語マーキング : 表の中の指定した単語を、任意の色でマーキング
       - 行マーキング   : 指定した文字を含む行を、指定した幅 (行全体 / 列の範囲 / 横位置) でマーキング
     列番号は「表の構造を確認」ボタンで確認できます。
  3. 「▶ マーキング実行」を押すと、<元の名前>_marked.pdf が保存されます。
     (出力フォルダを指定しない場合は、元の PDF と同じ場所に保存されます)

  お試し用に sample フォルダに sample.pdf を入れてあります。


■ ルールの保存
  - 「ルールを保存…」でルールを YAML ファイルに保存し、「ルールを読み込む…」で再利用できます。
  - このフォルダにある rules.yaml は起動時に自動で読み込まれます。
    よく使うルールは rules.yaml という名前でこのフォルダに上書き保存しておくと便利です。


■ コマンドラインでの利用 (上級者向け)
  pdf-auto-marker.exe を使うと、バッチ処理などに組み込めます。

    pdf-auto-marker.exe 入力.pdf -c rules.yaml -o 出力.pdf
    pdf-auto-marker.exe 入力フォルダ -c rules.yaml -o 出力フォルダ
    pdf-auto-marker.exe 入力.pdf --inspect        (表の行・列を表示)
    pdf-auto-marker.exe --help                    (オプション一覧)


■ 注意事項
  - スキャン画像のみの PDF は文字情報がないため対象外です。事前に OCR してください。
  - 罫線のない表は、オプションの「表の検出方法」を「文字の並びから検出」にしてください。
  - パスワード付き PDF には対応していません。
  - マーキングは PDF の注釈として付くため、Acrobat などで個別に削除・色変更できます。


■ ライセンス
  PDF 処理に PyMuPDF (AGPL-3.0) を使用しています。
